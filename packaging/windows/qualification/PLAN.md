# Bristlune disposable installed qualification

Approved scope: exact-source native runtime staging, disposable MSIX installation,
real painting/save/export/reopen UI, independent files/pixels, normal stop,
uninstall and owned fixture/profile/display cleanup. Public release/source/license
clearance is not inferred from this qualification; the audited release builder
remains separate and unchanged in its clearance requirements.

1. Bind the successful six-suite CMake install inventory to the current clean
   source and native run/attempt. Reconstruct the locked dependency stage from
   the pinned archives, select explicit runtime locations, reject conflicting
   copies and record every source path, hash and locked package owner.
2. Generate the fixed Bristlune qualification manifest/assets. Use the exact
   Windows SDK version/path, record its executable hashes and verify before each
   invocation. Independently verify container and SDK-unpacked payload. No
   native binary or package artifact is uploaded by the qualification workflow.
3. Exclusively own the temporary fixture and fresh established profile locations;
   refuse existing application registrations/profile data. Sign only a private
   temporary copy with a non-exportable certificate, install, then activate via
   the package broker. Retain and verify the exact process handle, executable
   bytes, package identity and native main-window owner.
4. Through real UIA/native input: New Document, explicit width/height 512×384,
   Create, Save As blank.kra, freehand brush stroke, Save As artwork.kra, Export
   artwork.png, open that PNG and Save As reopened.kra. The selected native
   picker must have the retained process and an owner chain to the exact main
   window before any input. Unproved control/ownership becomes a failure with
   bounded metadata and an unedited owned-window capture, never guessed input.
5. Independently decode the KRA merged images and exported PNG. Require the exact
   dimensions, changed painted pixels over the blank image, matching exported
   pixels, reopened content equality and unchanged protected bytes. Verify loaded
   native modules against the package and Windows runtime boundaries.
6. Require normal process exit, uninstall, unchanged original package, removal of
   only unchanged owned fixture/profile/certificate state, and restoration of an
   enumerated native desktop mode. Record failure and cleanup separately.

The Mac has very limited free storage. Only source, tests and small metadata are
created locally; runtime and SDK execution require the Windows runner.
