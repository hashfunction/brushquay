# BrushQuay original artwork

Created September 11, 2026 for Trieflow LLC. The SVG icon, wordmark and geometric splash composition are original source-authored artwork, dedicated to CC0-1.0 by Trieflow LLC. They contain no upstream mascot, logo, embedded font, external image, or network resource. The wordmark uses the viewer's sans-serif font.

PNG derivatives were rendered from these SVG masters with `build-tools/brushquay-art/render.cpp`, Qt 6.11.2 QSvgRenderer / QImage and AppleClang 21.0.0.21000101 on macOS arm64. This uses QCoreApplication and opens no window. The SVG source is authoritative; PNG hashes and dimensions are recorded in artifacts.json. Exact pixel reproducibility across other Qt versions is not assumed. The runtime renders the wordmark SVG with its native font.

This provenance covers only these original BrushQuay assets. Upstream interface icons, brushes, profiles and other bundled material still require their separate file-level license audit.
